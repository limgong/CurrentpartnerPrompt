现任 · 使用说明

把一个人，留在一个窗口里。

不用懂代码。照着做就行。

这个程序读一份微信聊天记录，做出一个"像他一样说话"的对话窗口：你打字，它用他的语气、习惯和记得的事回你。

它不会真的联系到他，只是在你电脑上跑的一个模拟。

五分钟上手

  1. 装环境：右键 setup.ps1 → 使用 PowerShell 运行，等到显示「环境就绪」。
  2. 启动：双击 启动.bat，等 5–10 秒会出现「现任」窗口。
  3. 填 API Key：首次会自动跳到配置页；去 platform.deepseek.com 创建 Key，粘贴进来点「保存并验证」。
  4. 开始聊：底部输入，按 Enter 发送。
Key 只保存在你电脑的 .env 里，不会上传。每人用自己的。

人设卡是什么

程序每次回答前都会先读这张卡。卡写得像，回答就自然；卡写得空，回答就很假。

段落写什么
你是谁关系、称呼、现在各在哪做什么
当前状态截至最近一个月，他在做什么、关系到哪一步
关系变化按年月列关系怎么变的，每条「某年某月：发生了什么」
共同经历一起做过的事，每条带年月
怎么说话平均几个字、用不用标点、爱用什么词
口头禅 / 表情码真实出现过的说法和表情
示例6–8 组真实对话，学语气最直接
绝对不要禁忌：他最讨厌的说话方式
两种改法：控制台直接改并保存；或聊天时用 / 命令（推荐）。

斜杠命令

在聊天框输入以 / 开头的话，发出去，它会把人设卡改掉。

说话规矩

你打的字指的是谁
「你」他（被模仿的人）
「我」你自己

例子

/你上周去了日本看樱花，回来给我带了抹茶
/他最近开始实习了，在某市做数据
/2025年3月那次吵架是因为他放我鸽子
/他笑的时候说「乐」不说「哈哈」

会自动放到哪

你说的是放到
现在在哪、做什么、关系怎样当前状态
某年某月发生了什么、怎么变的关系变化
怎么说话、口头禅、表情怎么说话 / 口头禅
不能提的事绝对不要

其它命令

命令作用
/undo撤销上一次修改
/clear清空你和它的聊天记录（人设卡不动）
每次修改前都会自动备份，控制台「修改记录」里可以回滚到任意一版。

怎么让它更像

按重要程度排：

顺序做什么
1把「你是谁」写准：关系、称呼、现在各在哪、到哪一步
2「关系变化」补成 5 条以上，每条带年月
3「示例」放 8 组真实对话
4「怎么说话」写清：平均几个字、用不用标点、爱用哪个表情
5调状态滑杆：亲密高更黏，耐心低更敷衍
6调记忆配比：虚假权重太高会串味

加一个新的人

  1. 控制台 → 联系人 → 点「添加…」
  2. 从列表里选一个有聊天记录的会话
  3. 点「添加」，等 10–20 秒

它会自动抓双方微信头像、抽样聊天、调 AI 写一份人设卡。

消息少于 50 条不会生成人设卡，会留一个空模板给你手写。

更新聊天记录

微信每天有新消息，想让"他"知道就要更新。

前提：微信客户端正开着且已登录；装过解密依赖（setup.ps1 -WithDecrypt）。
  1. 控制台 → 数据 → 点「更新聊天记录」
  2. 弹 UAC，点「是」
  3. 等 30–60 秒，看到 decrypt exit=0 和新的条数

点「否」会失败，日志里会写「解密失败」。

出问题怎么办

窗口打不开

双击 debug_server.bat，它会停住显示报错。把那段文字发给懂电脑的人。

网页打不开

关掉重开；还不行就用浏览器手动打开 http://127.0.0.1:7860。

回复是空的

打开 out\serve_api.log 看最后 20 行，关掉重开。还不行就把报错发人。

提示 401 / 未配置 API key

打开 http://127.0.0.1:7860/setup 重新填 key。

它回的完全不像

先确认顶部是不是你要的那个人 → 看人设卡「你是谁」「示例」写没写 → 调低「虚假」权重 → 用 / 补几条具体习惯。

它瞎编没发生过的事

在「绝对不要」加一条「不要编造没发生过的见面」，调低「虚假」权重，删掉事实库里错的条目。

解密失败

检查：微信开着并登录了吗？UAC 点了「是」吗？跑过 setup.ps1 -WithDecrypt 吗？

名词解释

词意思
人设卡写着他是什么样的人的文档，最重要
事实一条条短结论，如「他在上海读研」
记忆原始聊天片段，被检索出来当参考
真实 / 朋友圈 / 虚假三种记忆来源：真聊天 / 朋友圈 / 和 AI 聊的
状态四个滑杆，控制他此刻的心情
虚拟对话之前和 AI 分身聊出来的内容，不是真事
三级检索搜不到就换更宽的搜法，最多试三次

别做的事

❌ 别把 .env（API Key）发给别人

❌ 别把 persona/profiles/ 传到网上（里面有聊天和人设卡）

❌ 别用这个程序登录他的微信、冒充他发消息

❌ 别拿别人的聊天记录做，除非对方同意
