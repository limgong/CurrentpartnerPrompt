# 现任（Xianren）

> 把一个人，留在一个窗口里。

[![repo](https://img.shields.io/badge/github-limgong%2FCurrentpartnerPrompt-181717?logo=github)](https://github.com/limgong/CurrentpartnerPrompt)
[![license](https://img.shields.io/badge/license-MIT-07c160)](LICENSE)

用一个真人的微信聊天记录，做一个"说话像他、记得住事、会承认不知道"的对话人格。

**不训练模型。** 用「人设卡 + 事实库 + 记忆检索 + 认知过滤」四层结构，调用 DeepSeek 生成回复。

---

## 一、这是什么

传统做法是拿聊天记录去微调模型，但小模型学到的只是"语气"，学不到"判断力"。
这个项目换了个思路：

```
你说话
 → 规划器判断：要不要查记忆、查什么
 → 三级检索：关键词 → DeepSeek 改写检索词 → 二元组兜底
 → 认知过滤：他现在知道这件事吗？该主动提吗？
 → 拼 prompt：人设卡 > 事实 > 记忆 > 此刻状态
 → DeepSeek 流式生成
```

所以它能把三件事分开处理：

| 能力 | 靠什么 |
|---|---|
| 说话像 | 人设卡 + 真实对话示例 |
| 记得住 | 22 万条消息的检索 + 事实库 |
| 有分寸 | 知识边界（不知道未来）+ 情绪边界（不硬安慰）|

## 二、功能一览

### 聊天

- 微信风格气泡（左白右绿）、头像、时间分隔（今天 / 昨天 / M月d日）
- 流式出字，首字约 0.7–2 秒
- 刷新不丢对话，每个联系人独立历史
- 支持 `/` 指令直接修人设卡

### 控制台（`/admin`）

| 区域 | 能做什么 |
|---|---|
| 联系人 | 切换、添加（自动抓微信头像 + 生成人设卡）|
| 记忆构成 | 真实聊天 / 朋友圈 / 虚拟对话 分别多少条 |
| 人设卡 | 全文查看、编辑、保存、撤销、**用 AI 重新生成** |
| 修改记录 | `/` 修改的时间线，可回滚到任意一版 |
| 状态 | 亲密/信任/耐心/兴趣 四维滑杆（影响语气）|
| 记忆配比 | 三类记忆权重 + 「他说多少」（主动↔敷衍）|
| 数据 | 更新聊天记录、重建索引、清空 AI 对话、抓头像、退出 |

### 人设卡自动生成

新加一个联系人时，会自动：

1. 从 `head_image.db` 抓双方头像
2. 抽样真实对话（可调 20–150 组）
3. 调 DeepSeek 写出带**时间线**的人设卡：
   - `当前状态（截至某月）`
   - `关系变化`（按年月列出关系怎么演变）
   - `共同经历`（每条带年月）
   - `怎么说话`（用统计数据写成规则）
   - `口头禅` / `表情码` / `示例` / `禁忌`

### 三级记忆检索

```
① 关键词（BM25 + IDF 加权覆盖）
   命中判定：稀有词必须命中，"那次""的"这类常见词不算
        ↓ 命中不足
② DeepSeek 改写检索词（语义近似）
   "爬到山顶累得腿都不是自己的了" → ["爬山","登顶","腿软"]
        ↓ 还不够
③ 二元组兜底（最宽松的字面匹配）
```

只有搜不到才升级，所以平时不增加延迟。

## 三、部署

### 前置条件

- Windows 10/11
- Python 3.11+（推荐 3.12）
- DeepSeek API Key（[platform.deepseek.com](https://platform.deepseek.com) 申请，每人用自己的）

### 步骤

```powershell
# 0. 克隆
git clone https://github.com/limgong/CurrentpartnerPrompt.git
cd CurrentpartnerPrompt

# 1. 装环境（自动找 Python、建 venv、装依赖、检查）
powershell -ExecutionPolicy Bypass -File .\setup.ps1

# 2. 启动
.\启动.bat
```

首次打开会跳到 `http://127.0.0.1:7860/setup`，让你填 API Key。
填完点「保存并验证」，程序会真实调一次接口确认可用。

### 如果要导入微信聊天记录

```powershell
# 装解密依赖（多 pymem / yara-python）
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -WithDecrypt

# 解密（会弹 UAC，点「是」）
.\decrypt.bat
```

解密依赖开源项目 `LifeArchiveProject/WeChatDataAnalysis` 的源码部分，原理是从运行中的微信进程取密钥。
**微信必须正在运行且已登录**，否则拿不到密钥。

## 四、需要你亲自动手的事

下面这些程序做不到或不该代劳：

| 事项 | 为什么必须你来 |
|---|---|
| **填 API Key** | 每个人用自己的 key，不要共用 |
| **点 UAC 同意** | 读微信进程内存需要管理员权限，必须本人确认 |
| **填写「你是谁」** | 关系、称呼、近况只有你知道；程序只能给模板 |
| **校对事实库** | 规则抽的 213 条里必有错的，错一条会被一直引用 |
| **添加联系人** | 选哪个会话做人设，是你的判断 |
| **确认 / 修改人设卡** | AI 生成的是草稿，情感细节要你补 |
| **决定隐私边界** | 哪些聊天能给模型看，你自己定 |

## 五、使用方法

### 聊天

打开窗口 → 底部输入 → Enter 发送（Shift+Enter 换行）。

底部状态栏会显示本轮命中了哪些记忆。

### 修人设卡

在聊天框输入 `/` 开头的句子：

```
/他笑的时候说「乐」不说「哈哈」
/你上周去了日本看樱花，回来给我带了抹茶
/2025年3月那次吵架是因为他放我鸽子
```

规则：

- 「你」= 被模仿的人，「我」= 你自己
- 会按内容**自动落到对应段落**（当前状态 / 关系变化 / 说话方式 / 禁忌）
- 会带最近 10 条对话作为上下文，理解「刚才说的那个」这种指代
- 改前自动备份，`/undo` 回滚

其它指令：

| 指令 | 作用 |
|---|---|
| `/undo` | 撤销最近一次修改 |
| `/clear` | 清空当前联系人的对话记录 |

### 控制台

浏览器打开 `http://127.0.0.1:7860/admin`，或在聊天页点「控制台」。

## 六、可能会遇到的问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击 `启动.bat` 一闪而过 | 旧版脚本没有 pause | 用当前版本；或跑 `debug_server.bat` 看报错 |
| 网页打不开 | 服务没起来 / 端口被占 | `debug_server.bat` 前台跑，看报错；换端口设 `APP_PORT` |
| 浏览器黑屏 | Edge 应用模式 + GPU 合成 | 已加 `--disable-gpu`；仍不行就换默认浏览器打开 `127.0.0.1:7860` |
| 回复是空白 | 接口 500（历史表结构缺列等） | 看 `out/serve_api.log`；重启服务会自动补列 |
| `401 Unauthorized` | API Key 无效或没余额 | 打开 `/setup` 重新填 |
| 提示「未配置 API key」 | `.env` 为空 | 同上 |
| 解密失败 | 微信没开 / UAC 点了「否」 / 缺依赖 | 先 `setup.ps1 -WithDecrypt`，确认微信登录，重跑 `decrypt.bat` |
| 解密后是乱码 | 长消息被 zstd 压缩 | 项目已内置解压，确认用的是 `memstore` 而不是旧脚本 |
| 记忆搜不到 | 关键词太泛 / 语义不同 | 换具体说法；或看控制台「修改记录」里检索阶段 |
| 人设不生效 | 改的是模板不是当前联系人 | 控制台确认顶部联系人名字 |
| 加联系人没生成人设卡 | 消息太少 / 没配 key | 少于 50 条不生成；确认 key 有效 |

## 八、隐私与合规

**这个仓库不包含任何聊天数据。** 运行后会在本地生成：

| 路径 | 内容 | 是否提交 |
|---|---|---|
| `.env` | API Key | ❌ |
| `persona/profiles/` | 人设卡、事实库、状态、头像 | ❌ |
| `persona/backups/` | 人设卡历史版本 | ❌ |
| `out/` | 解密后的数据库、记忆索引 | ❌ |
| `workspace/` | 对话历史、日志 | ❌ |

`.gitignore` 已全部排除。**提交前请 `git status` 确认。**

合规提醒：

- 只能处理你自己账号的数据，或已获明确同意的对方数据
- 微信官方对本地库解密持负面态度（同类工具曾被律师函下架），仅限个人本地使用
- 不要接管真实微信账号自动回复，那是冒用他人身份

## 九、已知限制

- 检索是 BM25，字面不同但意思相同的说法要靠 DS 改写兜底
- 回复偏短（模型比真人更惜字），长句（10–25 字）出现率低
- 事实库需人工校对
- 朋友圈只能拿到本机缓存过的文字动态
- 无联网搜索（规划器会判断 `need_web`，但没接搜索服务）
