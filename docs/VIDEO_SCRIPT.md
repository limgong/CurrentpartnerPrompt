## 录前准备

### 要开的窗口（按出场顺序）

| 顺序 | 窗口 | 状态要求 |
|---|---|---|
| 1 | 文件资源管理器 | 停在项目根目录，能看到 `debug_server.bat` |
| 2 | 命令行 | 还没启动，用来双击 bat |
| 3 | 浏览器标签 1 | `http://127.0.0.1:7860`（聊天页）|
| 4 | 浏览器标签 2 | `http://127.0.0.1:7860/admin`（控制台）|
| 5 | 浏览器标签 3 | `http://127.0.0.1:7860/help`（说明页，结尾用）|

### 隐私处理（必做）

- 用一个**演示档案**，不要用真实联系人
- 人设卡里把昵称、城市、学校全换成演示值
- 关掉微信、通知、输入法候选框
- 任务栏隐藏，浏览器书签栏隐藏（`Ctrl+Shift+B`）

### 拍前试跑三句话

```
在干嘛
你还记得那次旅行吗
我想你了
```

确认三句都能正常流式出字，再开机录。

## 演示时要说/要打的字

### 聊天（镜头 5、6、7）

```
你还记得那次旅行吗
我想你了
```

> 不要用真实地名、真实人名。真被问到具体事，用"那次旅行"这种模糊说法。

### 斜杠指令（镜头 8）

```
/你上周去了趟外地，回来给我带了点心
```

预期：控制台人设卡「当前状态」多一条 2026-xx 的记录。

### 状态滑杆（镜头 7）

- 耐心：从 60 拖到 15
- 回聊天发：`在干嘛`，预期回复变成一两个字或「嗯」

## 拍摄提示

| 项 | 建议 |
|---|---|
| 分辨率 | 1920×1080，浏览器缩放到 110%，字大一点 |
| 帧率 | 30 fps 够 |
| 鼠标 | 移动放慢，停顿 0.5 秒再点 |
| 打字 | 用输入法一次打完整句，不要在镜头里改错字 |
| 等待 | 流式出字时不要切镜头，那是主角 |
| 剪辑 | 每段之间留 0.3 秒黑场，节奏不赶 |
| 音乐 | 低频钢琴或 lo-fi，音量压到 -24 dB，别盖人声 |
| 字幕 | 中文字幕常驻，关键词（人设卡／三级检索／认知过滤）加粗 |
