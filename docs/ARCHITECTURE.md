# 现任 · 工作流总结

## 一、数据从哪来

```
微信 4.0 本地库（SQLCipher 加密）
   ↓ 取密钥（内存扫描，管理员权限）+ 解密 25 个 db
解密后的 SQLite（message_0..7.db，按时间分片）
   ↓ 关键一步：长消息是 zstd 压缩的（魔数 28 B5 2F FD，肉眼像 "(/"）
解压后得到全部文本
   ├─ 私聊 105,444 条（阿七 ↔ 小极）
   └─ 群聊 116,304 条
   ↓ 两路分流
   ├─ 训练数据：合并连发 → 上下文配对 → 20,322 对（本次未用于训练）
   └─ 记忆库：滑窗切块 → 73,037 块 → BM25 索引
```

## 二、四层人格资产

| 层 | 文件 | 内容 | 规模 |
|---|---|---|---|
| **L0 人设卡** | `persona.md` | 关系、共同经历、冲突史、情绪边界、说话方式、口头禅、表情码、作息、示例、禁忌 | 2,994 字符 ≈ 1,871 token |
| **L1 事实库** | `facts.db` | 结构化事实（plan/promise/preference/event/relationship），带时间与置信度 | 213 条 |
| **L2 情景记忆** | `memory_index.pkl` | 6 条消息一窗、步长 3 的原文块，BM25 + 时间衰减（半衰期 730 天） | 73,037 块 ≈ 39 MB |
| **L3 状态** | `state.json` | 四维好感度（亲密/信任/耐心/兴趣），基线 50，单轮 ±5，每日回落 1，可回滚 | 实时 |

## 三、Prompt 结构（每轮现拼）

```
┌─ system（约 3,283 字符 / 2,051 token）
│  ├─ L0 人设卡全文（不做摘要，保持原文风格）
│  ├─ "## 你们之间的一些事" + L1 命中的事实（按关键词打分，top 5）
│  ├─ "## 你记得的片段（只作回忆，不要复述，不要带日期）" + L2 top 3
│  └─ "## 此刻的状态" + 一句话语气描述（如"有点不耐烦，回复要更短"）
├─ 最近 6 轮对话（从 history.db 读）
└─ 本轮用户输入
```

命中示例（问"你还记得山里那次吗"）：

```
事实: 2026年7月底一起去某市和山里…
记忆: （2026-06-30）有火车吗 / 阿七 大巴是山里北-山里汤口镇哦…
状态: 状态平稳（亲密50/信任50/耐心50/兴趣51）
```

## 四、运行时流程

```
浏览器输入
   ↓ POST /api/chat
hist_load(60)               读最近 60 条历史
prompt_builder.build()      检索事实 + 记忆 + 状态，拼 system
hist_add("user", text)      先落库
stream_chat()               DeepSeek API，stream=True
   ↓ SSE
浏览器逐字渲染              同时显示"命中了哪些记忆/事实"
hist_add("assistant", …)    流结束后落库
```

实测延迟：首字 0.76–1.48 s，完成 0.8–1.6 s。

## 五、人设修正工作流（`/` 指令）

```
/他笑的时候说「乐」不说「哈哈」
   ↓ POST /api/persona/patch
读出当前 persona.md
   ↓ 调模型（temperature=0.2）做"合并"而非追加
生成新人设卡
   ↓ 校验：含 ## 你是谁、## 怎么说话，长度 400–12,000
备份旧版 → backups/persona-<时间>.md
写入 → 记录 patches.jsonl
   ↓
聊天区显示 ✅ 已合并（2994 → 3021 字）
```

`/undo` 恢复最近备份；`/clear` 清空对话。

## 六、当前指标

| ≤10 字占比 | 97%（真人 85%）|

| 首字延迟 | 0.76–1.48 s |
| 单轮成本 | 约 2.2k input + 20 output token |

## 七、已知限制

1. **长度偏短**：模型比真人更惜字，长句（10–25 字）几乎不出现。
2. **表情码不稳定**：同一张卡，有时 13%，有时 3%。
3. **检索噪声**：BM25 会命中"在干嘛"这类口头禅密集的块。
4. **事实库 213 条是规则抽的**，置信度 0.35，未人工校对。
5. **状态更新仍是规则版**（问句+兴趣、脏话−耐心），不是模型判断。
6. **人设卡已 2,994 字符**，再长会挤占记忆预算（提醒：`BUDGET.persona` 已调到 4,500）。
